HayBTech Payment Provider

Secure and seamless mobile payments for West Africa

The official HayBTech payment provider for Odoo. Accept mobile money and local payment methods effortlessly. This module integrates the highly secure HayBTech SDK to process transactions with absolute peace of mind.

  • 🔒 Bank-Grade Security: Advanced cryptographic webhook verification.
  • ⚡ Fast Processing: Immediate checkout and status updates.
  • 🌍 Local Methods: Support for mobile money across West Africa.
  • 🛠️ Easy Configuration: Simply paste your Secret Key and Webhook Secret.

Configuration

1. Go to Invoicing > Configuration > Payment Providers.
2. Select HayBTech.
3. Enter your Test/Live Secret Keys and Webhook Secret.
4. Change the state to Enabled.
